Anatomy of a chart prompt

A chart prompt that lands says what question the chart answers, names the chart and what each axis and color stands for, says how the scale works, and asks for the one annotation that makes the point. Here is what that looks like for three different jobs. Tap any word to jump to its card.

  • Lead with the question"Which channel grew fastest since 2023?" picks the chart for you. "Visualize this data" gets a default bar chart and a legend.
  • Map every columnSay which field goes on x, which on y, which sets color and which splits the panels. Ambiguity here is where most bad charts come from.
  • Ask for the title as a sentence"Airport sales nearly triple every summer" beats "Sales by location, 2025". The headline is the first thing anyone reads.
  • Name what to avoid"No dual axis, no 3D, no rainbow scale." Saying the failure out loud is quicker than describing the fix.
  • Say where it will liveA slide, a phone, a printed report and a live dashboard each want different sizes, fonts and amounts of detail.
