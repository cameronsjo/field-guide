Anatomy of a UI prompt

A UI prompt that lands names the platform, the structure, a few key components, a look, and one or two practices. Here is what that sounds like for four kinds of product. Tap any word to jump to its card.

  • Name the platform's own words"Bottom sheet" means something exact on Android; "sheet with detents" is the iOS version. Using the native name gets you native behavior.
  • Point at a real app"Navigation like Linear", "panes like lazygit". A reference carries dozens of decisions you'd otherwise have to spell out.
  • Describe every stateEmpty, loading, error and success. Unnamed states are the ones that come back half-built.
  • Name the stackSwiftUI, Jetpack Compose, React with Tailwind, Go with Bubble Tea. It decides which components Claude reaches for.
